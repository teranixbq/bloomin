# Laporan Perubahan - 14 Desember 2025

## Media Forwarding & Spam Detection

### Perubahan yang Dilakukan

#### 1. Media Detection Fix
**File:** `bot/main.py`

**Masalah:**
- Bot tidak bisa detect media dari GOWA webhook
- Pesan "Maaf kak..." muncul berulang kali (4x)
- Admin tidak menerima notifikasi

**Root Cause:**
- GOWA kirim media sebagai key langsung di payload (`image`, `video`, dll), bukan field `message_type`
- Flag `media_forwarded` disimpan di session yang bisa expire
- Notifikasi admin pakai `notify_owner()` tapi tidak dipanggil dengan benar

**Solusi:**
- Tambah deteksi media dengan check key di payload: `if "image" in payload`
- Pakai `_media_forwarded_users` set di level module (persist meskipun session expire)
- Panggil `notify_owner()` untuk kirim notifikasi ke admin via WhatsApp

**Kode:**
```python
# Detect media dari payload keys
if "image" in payload or "video" in payload or "audio" in payload or "document" in payload:
    sender_phone = get_sender_phone(payload)
    
    if sender_phone not in _media_forwarded_users:
        _media_forwarded_users.add(sender_phone)
        
        # Kirim notif ke user
        await send_message(
            sender_phone,
            "Maaf kak, bot tidak bisa membaca gambar/media. "
            "Saya akan alihkan ke admin."
        )
        
        # Forward ke admin
        owner_phone = get_owner_phone()
        await notify_owner(
            owner_phone,
            sender_phone,
            "User mengirim media yang tidak bisa dibaca bot"
        )
```

#### 2. Spam Detection
**File:** `bot/main.py`

**Fitur:**
- Detect spam saat jam kerja saja
- Threshold: 5+ pesan dalam 10 detik
- Auto-forward ke admin tanpa konfirmasi user
- Pakai `_spam_forwarded_users` set (persist)

**Kode:**
```python
from collections import defaultdict
import time

_message_history = defaultdict(list)
_spam_forwarded_users = set()

# Di webhook handler:
sender_phone = get_sender_phone(payload)
current_time = time.time()

# Bersihkan history lama (>10 detik)
_message_history[sender_phone] = [
    t for t in _message_history[sender_phone]
    if current_time - t < 10
]

# Tambah timestamp baru
_message_history[sender_phone].append(current_time)

# Check spam (hanya jam kerja)
if is_within_work_time() and len(_message_history[sender_phone]) >= 5:
    if sender_phone not in _spam_forwarded_users:
        _spam_forwarded_users.add(sender_phone)
        
        owner_phone = get_owner_phone()
        await notify_owner(
            owner_phone,
            sender_phone,
            "User melakukan spam"
        )
```

#### 3. Outside Hours Set Tracking
**File:** `bot/main.py`

**Perubahan:**
- Dari session-based ke set-based tracking
- `_notified_outside_hours` set persist di level module
- Auto-reset saat masuk jam kerja (clear set)

**Flow:**
```
23:00 - User A chat → reminder, masuk set
23:01 - User A chat → skip
23:05 - User B chat → reminder, masuk set
08:00 - Masuk jam kerja
08:15 - User C chat pertama → clear() seluruh set, proses normal
```
